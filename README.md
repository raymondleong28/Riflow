# R-PRM

**R-PRM** is an independent, self-hosted partner relationship management (PRM) application for a single installing organisation. It manages partner programs, tiers and commission rules, partner applications and onboarding, leads, deals, customers and transactions, rewards and payouts, enablement content, and a dedicated partner portal.

- **Self-use, single organisation:** No vendor super-admin, no external sign-up, and no subscription billing.
- **Starts empty:** A newly migrated database contains zero partners, programs, or accounts. Opening the application for the first time redirects to `/setup` to create the workspace and first administrator.

See [docs/PRODUCT.md](docs/PRODUCT.md) for a complete feature breakdown and [docs/GO-LIVE.md](docs/GO-LIVE.md) for production deployment instructions.
